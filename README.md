# Sanji Dewe

I build software systems and the engineering foundations behind them.

My work is centered on software and platform engineering, system architecture, developer tools, and the reliability of the systems people depend on. I’m particularly interested in the difficult parts of building technology: clear boundaries, predictable behavior, careful validation, and designs that remain understandable as they grow.

## What I work on

- **Software and platform engineering** — designing and building dependable software foundations.
- **System architecture** — modularity, clear interfaces, and well-defined responsibilities.
- **Developer infrastructure** — tools and workflows that make engineering work more reliable.
- **Validation and reliability** — testing assumptions, checking behavior, and using evidence to guide decisions.

## Building

I’m developing **SanovaBase**, an independent technology platform, alongside foundational engineering projects and experiments.

I prefer to build from first principles, verify claims against working implementations, and keep the core of a system useful without unnecessary dependencies. The goal is not to ship quickly at any cost, but to build technology that can be understood, maintained, and trusted.
